折腾了几天，这个主页终于上线了。

选型的纠结过程其实很短：**Astro + 手写样式**。理由很简单——我要的是纯静态、能直接丢到 GitHub Pages 上、又能用 Markdown 写博客。Hugo 和 Jekyll 主题多，但极简风反而要跟主题打架，不如从零写 CSS 来得干净。

## 这里会有什么

- **博客**：学习记录、踩坑、读书笔记，想到什么写什么
- **研究**：LLM Agent 相关的方向和进展
- **项目**：做完的东西，能开源的都开源
- **刷题**：LeetCode 记录，构建时自动拉数据
- **简历**：一页纸，随时更新

## 怎么加一篇新文章

在 `src/content/blog/` 下新建一个 `.md` 文件，开头写上：

```yaml
---
title: 文章标题
date: 2026-09-20
summary: 一句话摘要，会显示在列表页
tags: ['标签1', '标签2']
---
```

然后 `git push`，GitHub Actions 会自动构建部署。

## 关于设计

全站只有一个强调色，其余全是黑白灰。想换颜色的话，改 `src/styles/global.css` 顶部的 `--accent` 一行就够了。

留白比装饰更重要——这是我唯一坚持的原则。
